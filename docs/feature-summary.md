# Hypnosis Add-on — Feature Summary

*Both players need the add-on installed unless noted. ✅ = built · 🔧 = in progress or planned*

---

## Session Flow

| Feature | Description | Status |
|---------|-------------|--------|
| **Induction attempt** | Hypnotist presses a button; subject privately chooses to agree, ignore, or fight | ✅ |
| **AFK protection** | If the subject doesn't respond, attempt is blocked — hypnotist is told it's not a good time | ✅ |
| **Success roll** | Whether induction lands depends on trust, skill, depth of resistance, and modifiers like arousal | ✅ |
| **Trance depth** | Five tiers — Drifting, Yielding, Entranced, Deep, Blank. Depth determines what the hypnotist can do | 🔧 |
| **Induction RP window** | Time for actual roleplay before the roll; hypnotist is rewarded for engaging | ✅ |
| **Progress hints** | Hypnotist sees if the subject is getting closer without knowing their private choice | ✅ |
| **Max attempts** | Hypnotist locked out after too many failed tries; cooldown required | ✅ |
| **Fractionation** | Re-inducing shortly after waking gives a depth bonus — each drop goes a little deeper | 🔧 |

---

## While Under — What the Hypnotist Can Do

| Feature | Description | Status |
|---------|-------------|--------|
| **Freeze** | Subject cannot move (BC native — works without subject's add-on) | ✅ |
| **Rooted** | Feet stuck but arms free — movement blocked, gestures still work | 🔧 |
| **Speech control** | Subject speaks only when permitted, or is compelled to repeat phrases | ✅ |
| **Follow** | Subject must follow the hypnotist, including across rooms | ✅ |
| **Remove clothing** | Gradual compulsion to undress, one item at a time | ✅ |
| **Arousal suggestions** | Set arousal level, force orgasm, or deny — four levels | ✅ |
| **Natural language** | Suggestions recognized from normal chat; no slash commands required | ✅ |
| **Self-touch block** | Subject cannot touch themselves | ✅ |
| **Body part protection** | Block others from touching specific areas | 🔧 |
| **Command authority** | By default only the session hypnotist can give commands; can be opened to others | 🔧 |

## Perception & Illusion

| Feature | Description | Status |
|---------|-------------|--------|
| **Clothing illusion** | Subject sees themselves dressed when they aren't (or vice versa) | ✅ |
| **Bondage illusion** | Subject feels restrained when nothing physical is holding them | 🔧 |
| **Phantom sensation** | Subject feels touch that isn't there, or doesn't feel touch that is | 🔧 |
| **Screen fade** | Subject's view dims or fades during trance | ✅ |
| **Awareness suppression** | Subject doesn't notice clothing changes, room activity, etc. | ✅ |

---

## Triggers (Planted Effects)

| Feature | Description | Status |
|---------|-------------|--------|
| **Plant a trigger** | During trance, hypnotist installs a keyword and effect that fire later in normal conversation | ✅ |
| **Trigger scope** | Control who can activate the trigger — just the hypnotist, owner, everyone, etc. | ✅ |
| **Trigger discovery** | During a session, hypnotist can probe for existing triggers — what surfaces depends on trance depth | 🔧 |
| **Trigger removal** | Another hypnotist can remove a trigger if they reach sufficient depth | 🔧 |
| **Carry-forward** | Suggestions made in trance continue to apply after waking for a set duration | ✅ |
| **Trigger reinforcement** | Using or re-planting a trigger keeps it strong; ignored triggers fade over time | 🔧 |
| **Induction trigger** | A special trigger that initiates a trance *attempt* when heard — subject still gets to fight it | 🔧 |
| **Persona / alter ego** | A trigger that shifts personality; add-on nudges wardrobe to match the persona | 🔧 |

---

## Trust & Relationships

| Feature | Description | Status |
|---------|-------------|--------|
| **Trust system** | Trust builds through time and sessions; determines depth ceiling and feature access | ✅ |
| **Trust decay** | Trust fades with time if interaction stops — rate is configurable, off by default | ✅ |
| **BC relationship floors** | Friends, lovers, and owners get a guaranteed minimum trust level | ✅ |
| **Trust milestones** | Flavor messages appear as trust meaningfully increases | 🔧 |
| **Hypnotist skill** | Global skill grows across all subjects; makes inductions more reliable | ✅ (partial) |
| **Subject experience** | Being hypnotized builds experience — helps you go under for trusted hypnotists, resist strangers | ✅ (partial) |

---

## Roles

| Feature | Description | Status |
|---------|-------------|--------|
| **Architect** | One designated person with highest access — can set configuration, manage triggers at any depth. Granted via wizard (from BC relationships) or trust threshold + request | 🔧 |
| **Extreme subject mode** | Opt-in lock where only the Architect can make changes; trigger decay disabled; settings gated behind a time lock | 🔧 |

---

## Safety & Control (Subject-Side)

| Feature | Description | Status |
|---------|-------------|--------|
| **Safeword** | Always works — exits trance immediately regardless of depth or settings | ✅ |
| **Hard limits** | List of features that can never be used on this subject, regardless of trust | ✅ |
| **OOC preference** | Set whether mechanics actually work (cosmetic RP only / genuine resistance / hard no) | ✅ |
| **AFK block** | No answer = no hypnosis. Hard block, no skill override | ✅ |
| **Session timeout** | Subject sets a max session length; trance ends automatically | ✅ |
| **Lock settings in trance** | Settings panel disabled while under so the hypnotist can't make you change them mid-session | ✅ |
| **Export / import / reset** | Back up or wipe your full hypnosis profile | ✅ |
| **Player vs. Architect control** | Subject chooses who holds highest authority over their settings | 🔧 |
